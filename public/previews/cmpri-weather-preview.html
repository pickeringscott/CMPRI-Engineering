    CMPRI integration & preview limits

    • Reviewed Engineering dashboard, DesktopWindow, profile / phone notifications, shared palette, and seasonal-theme guidance. Current theme: Illinois / Iowa. No applicable root or source AGENTS.md was present; the discovered AGENTS.md is in an archived subfolder.
    • Matches shared black / charcoal, orange / gold, Arial, compact Operations launcher, window titlebar, dark panels, and full-width mobile view.
    • The Engineering launcher uses the native movable / resizable DesktopWindow and existing dashboard authentication. Embedded content mirrors the palette locally. Notification preferences, installed-app behavior and real schedules are demonstrations; profile persistence is not connected.
    • Preview preferences and delivery keys are in memory. Native per-day schedules, role eligibility, phone registration, and saved profiles are not implemented. No warning or freeze safety action is a real push.

    Test policy: stale observations, missing scans, stale forecasts and failed alert requests must stay labeled stale / unavailable. A successful empty alert response may say “No active alerts returned at [checked time]”; a failed response may not. The Weather tab reports the actual alert request status and time.
