    Official products & verification

    Reviewed Nov 19, 2026

    Published NOAA/NWS and IDOT sources are listed below. Default weather and safety examples are simulated. “Refresh NOAA map feeds” makes foreground read-only requests only to NOAA after Weather opens. A layer is called live only after valid data loads; failure leaves it unavailable. No CMPRI API, Supabase, scheduler or push is used.

    CMPRI styling & standalone differences

    • Read-only review of Engineering dashboard, DesktopWindow, profile / phone notifications, shared palette, and seasonal-theme guidance. Current theme: Illinois / Iowa. No applicable root or source AGENTS.md was present; the discovered AGENTS.md is in an archived subfolder.
    • Matches shared black / charcoal, orange / gold, Arial, compact Operations launcher, window titlebar, dark panels, and full-width mobile view.
    • Cannot share the native palette import, movable / resizable multiwindow state, seasonal animated stadium, authentication / permissions, profile persistence, installed-app behavior, or real notification schedules.
    • Preview preferences and delivery keys are in memory. Native per-day schedules, role eligibility, phone registration, and saved profiles are not implemented. No warning or freeze safety action is a real push.

    Test policy: stale observations, missing scans, stale forecasts and failed alert requests must stay labeled stale / unavailable.
